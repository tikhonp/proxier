Press ? anywhere for this list. The bottom line shows the keys for what is under the cursor.

  • About twenty keys. Single letters, or a habit from vim: j k, gg G, /, :, y.
  • Letters never fire inside a field. esc leaves the field and they work again.
  • Nothing that deletes has a single key: use its button or :, then type the name.
  • Arrows, tab and ↵ always work too, so none of this is required.
